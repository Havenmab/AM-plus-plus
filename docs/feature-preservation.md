# 功能保全与验收矩阵

本矩阵定义每个 Apple Music 精确构建的功能要求、适用边界和人工验收场景。适配流程见 [宿主适配手册](host-adaptation-guide.md)，逐项工作模板见 [适配清单](host-adaptation-checklist.md)。

版本登记、源码/DEX 匹配、APK 构建、能力安装和人工验收分别记录。已登记支持不等于全部场景通过；已知不支持和已知降级也不应写成待验证的正常功能。

## 1. 适用边界

版本、页面族、生产资格和各能力标志以 [host-profiles](../host-applemusic/src/main/resources/host-profiles/) 为准。“已登记”指 profile 允许能力接入，实际运行还受设置、设备形态、Android API 和契约解析结果限制。本矩阵维护共享要求，具体版本映射和验收记录分别保存在 profile 与任务记录中。

未登记组合保持不支持。新增版本应独立使用本矩阵验收，不能继承相邻构建的人工结果。旧 Activity 行为以既有档案和冻结夹具为依据；通用文档更新不替换冻结基线。

### 页面族的行为差异

| 项目 | Activity 页面族 | Fragment 页面族 |
|---|---|---|
| 设置 | 原生 PreferenceFragment / PreferenceScreen 和 Activity 结果桥 | 原生 ViewModel、分类/action 模型、Compose 和结果桥 |
| 双栏 | 原有播放器状态及资源布局接入，独立右歌词 | Fragment 事务与视图会话，左 SONG/QUEUE、独立右歌词 |
| 玻璃 | 手机及符合既有条件的双栏平板横屏；平板为底部导航/mini 组合 | 手机底导航；平板顶导航与独立底部 mini，玻璃与双栏开关独立 |
| 媒体组件 | 保留该族的原生控制区 | 25% 控制区、附加音量控件和右下原生动作代理 |
| 视频 | 保留既有 Editorial 处理、预览及 Music Video 规则 | 原生视频策略；双栏外框与尺寸基准由当前视图会话统一维护 |
| 恢复 | 既有 Activity 生命周期和状态恢复 | view 身份、事务保存状态、封面/背景恢复和可关闭会话 |

这两类路径共享业务规则，但不具有完全相同的私有成员、设置模型和附加界面。每个构建依据自己的 profile 选择路径。

| 名称修正 | 原地区/cn/jp、原名/ISRC/ID 证据、查询与缓存优先级、离线及持久缓存，各显示表面独立安装 | 三种模式、切歌、网络/离线、各页面显示与点击 | HLE 各表面、目录与元数据缓存 |

| 底栏随滚动收缩 | 仅已登记的 7.0.0-beta 手机端开放，平板和旧版本保持展开且无相关设置；原生位移与 Compose 页面手势同向同阈值；底栏及 mini 上发起的手势不驱动收缩；mini 控件与打开播放器行为保持原生，无 mini 时允许收缩并中央留空；搜索项可分离时随进度分离；占用高度同步，切换项目/旋转/关闭开关后展开 | 页面拖动与惯性滚动、快速反向、列表首尾、横向/多指/取消、导航与搜索及 mini 起点归属、mini 有无、开关、旋转、切页、原生播放器收回落点 | profile 收缩资格、宿主滚动端口、手势跟踪、搜索语义、chrome 属性所有权 |
| 蜂窝入口 | 默认关闭；精确能力、构建安装归属、原生登录/类别及 availability 逻辑 | 已登录/未登录、开关、入口显示及原生操作 | 蜂窝能力和设置类别契约 |

| 更新与 ZIP | 批量、取消/进度、覆盖/保留冲突、事务恢复和既有格式 | 导出、导入、冲突、取消、中断和重新打开 | 更新、备份与恢复业务 |
| 存储与迁移 | schema15、原键/目录/文件 ID/marker/SQLite/cache；普通配置不覆盖资产；原子发布和只读重试 | 升级、回退、文件/缓存可用、事务中断 | 配置迁移、存储与索引事务 |
| 插件接口 | 独立 SDK、加载/生命周期/存储和冲突分析不受宿主混淆变化影响 | 已有插件加载、启停和设置，宿主降级边界 | plugin-api / plugin-runtime |

跨行歌词扫光是独立能力：它有自己的 profile 区域、契约、注册作用域与安装状态，与 CJK 辉光及末词补偿的开关、契约和降级互不影响；仅声明契约的精确版本适用，未声明版本标记不适用并按版本单独记录结果。静态遮罩恢复须区分未来行初始化与已唱词；从头播放、预加载、重新绑定或布局变化时，未开始的词及其前缀保持原生暗色。

跨行长 span 完成后，原生后继单行 span 在共享遮罩上保持已亮前缀和羽化前沿连续，保留后继的原版颜色、时间、调度与 `mask.i`。保护只来自已完成的跨行绘制及仍有效的几何，暗色、退场、Seek、换绑和布局失效释放；无此来源的单行扫光保持原生。人工验收应覆盖长段到短段交接，以及设备改变两行/三行排版后的同一分段。

## 3. 名称修正表面

每个表面应分别记录目标成员、辅助模型/binding、安装状态和三种模式的人工结果。单个表面显示正常不代表整项名称修正完成。

| 表面 | 验收内容 |
|---|---|
| 播放器 | 标题/艺术家与当前歌曲一致，切歌和原生操作保持 |
| 队列 | 列表、重绑定、当前项和点击后的歌曲一致 |
| 历史 | 更新后的标题/艺术家与原始数据归属正确 |
| 操作表 | 行内容、原生动作及选择对象正确 |
| 最近搜索 | 最近项与重新搜索后的结果一致，点击正常 |
| 资料库 | 模型/属性 getter、列表或 Compose、重建后的显示一致 |
| 专辑 | 标题/艺术家、容器与歌曲条目一致 |
| 歌单 | 容器、条目、刷新和原生操作保持 |
| 艺术家 | 页面及关联集合的名称证据与显示一致；已声明的 Compose 表面核对头部/top-songs 刷新、原名恢复、Success 切换和缺契约降级，见[专项清单](host-adaptation-checklist.md#artist-compose-profile-checks) |
| 主页与封面 | 主页模型/条目重绑定及实际封面加载路径正确，连续性有单独结果 |

Epoxy、DataBinding、Compose/LiveData、辅助 getter 和目录接口均属于表面依赖。因缺失或歧义降级的表面应明确标记，其他独立表面继续保留原生或已安装行为。

## 4. 平板双栏补充验收

共同门禁为已登记版本、双栏开关、横屏、宽度至少600dp及原生 useNavigationDrawer；其他形态保持原生路径。当前布局目标是左侧内容到屏幕50dp、右侧内容到歌词正文50dp；歌词自身留白保持原生。名义45%/55%分区与实际 host 宽度分别记录。

| 场景 | 验收标准 | 适用范围 |
|---|---|---|
| 首次打开/冷启动 | 左右内容正确、歌词视口可测量、标题/进度/播放按钮/音质标识同心，首帧无旧动作残留 | 两类页面族 |
| 横竖屏/多窗口/重建 | 门禁按有效配置变化、旧会话释放、恢复 tag/状态正确、逐字宽度重新对应实际视口 | 两类页面族 |
| 静态封面 | 基准为实际进度宽度与上方可用高度的较小值，居中；保留暂停 scale 和原生过渡 | 两类页面族 |
| 普通→普通 | 歌曲身份/文本一致，封面无旧尺寸往返，底部控件无额外闪现 | 两类页面族 |
| 普通→视频 | 外框中心和基准一致，视频按原生比例呈现，渐变及暂停规则正确 | Fragment 原生视频路径；旧族按其视频规则 |
| 视频→普通 | 纹理、模式和静态图同步恢复，无旧视频残留、额外外框往返 | 同上 |
| 视频→视频 | 相同和不同宽高比分别检查，原生比例过渡与额外位移区分，旧异步回调不操作新歌曲 | 同上 |
| SONG/QUEUE | 原生选择、点击和共享过渡保持；右侧独立歌词不替代左侧原生状态 | 两类页面族 |
| 歌词关闭/恢复 | Fragment 当前进度内容居中；切SONG/QUEUE不重置手动关闭；自动关闭与手动关闭区分 | Fragment |
| 换到无歌词歌曲 | 当前歌曲资格、网络许可和离线歌词共同决定可用性；旧文本/旧控件状态不能打开右栏 | Fragment |
| 展开/收起/反向拖动 | mini 到目标连续，原生 scale/Y 保留，X 补偿不累计；下半区保持预期位置 | 按页面族分别验收 |
| 音量 | 整个控件含图标与进度内容等宽；内部每侧40dp图标空间；短窗口、拖动和触摸区域正确 | Fragment 附加组件 |
| 底部原生动作/代理 | 原生被替代动作保留约束但不可见/不可点击，无残留反馈；代理 selector/tint/状态、队列点击/长按与歌词开关正确 | Fragment 附加组件 |
| 播放反馈/翻译 | 原生播放按钮尺寸/点击区域/间距保持，反馈与位置一致，翻译使用原生动作 | 按页面族分别验收 |
| 静态/视频暂停与后台 | scale、视频播放/暂停、背景采样和返回后的几何正确，无旧表面/背景残留 | 按页面族分别验收 |
| 退出双栏 | 模块监听与任务清理，仍拥有的属性恢复，原生布局/动作继续可用 | 两类页面族 |

当前 Fragment 的额外音量和代理组件不代表旧 Activity 具备相同界面。视频专项需要覆盖冷启动、歌曲切换、旋转、暂停和后台组合。

## 5. 玻璃与导航补充验收

| 场景 | 验收标准 |
|---|---|
| 手机导航/mini | 切页、重复点击、搜索、播放操作和原生页面选择正确；材质就绪后接管呈现 |
| Activity 平板横屏 | 按该构建的玻璃/双栏资格，导航与 mini 底部区域及收起/展开边界正确 |
| Fragment 平板 | 顶部导航、抽屉、独立底部 mini、单栏/双栏组合正确 |
| mini 启动恢复 | Fragment 手机与平板在既有玻璃接入范围共用恢复器；原生登录成立且当前对象存在时按原生显示契约恢复，每250ms、最多40次检查；延迟重试检查当前 owner/view，销毁后取消 |
| 按压/拖动/展开 | 点击与拖动反馈、取消、反向拖动和播放器过渡连续 |
| 收缩端点稳定 | 完全展开/完全收缩后继续滑动不来回抖动；连续同方向划动时抬手触点回带不反向改目标，未决短促滑动仅沿整次手势净方向补判；拖动手势拥有方向，惯性只延续确认方向；仅跟踪命中的列表，布局反馈不反向改目标；同目标不重启弹簧，真实快速反向仍连续 |
| 页面滚动边界 | 顶部/底部继续向边界外拖动不触发底栏收放；向内容内侧滚动仍有效；原生和 Compose 场景分别确认方向滚动能力，空页面和不足一屏的内容不因手指位移触发 |
| 底栏收缩 | 仅已登记的 7.0.0-beta 手机端开放，平板和旧版本保持展开并隐藏设置，旧平板收缩配置不生效；下滑收缩、上滑展开，Compose 页面同样成立，原生惯性滚动继续驱动；导航交互带、搜索和 mini 起点的整次手势不驱动收缩，移出区域也不改变归属；横向、多指与取消不误触发；搜索分离不抢同一次点击；点小胶囊展开、点搜索切页、mini 播放和打开播放器保持原生；无 mini 时仍收缩并中央留空；收缩态打开播放器时左右按钮下滑退出；三个控件同高（43dp）且与展开态底边等高，图标同心；mini 下沉回弹及两个方向的回弹幅度可配，回弹朝向 mini、展开外扩受间隙限制；**玻璃背板有回弹而水滴选择器没有**；按压高亮同形，搜索选中时使用强调色；共用收缩弹簧，占位和留白同步；切页/旋转/关闭开关后展开，原生 sheet 收回落点修正保留 |

## 6. 已知能力缺口

具体缺口读取当前 profile 的 `knownDegradations`、能力资格与安装报告，按独立子面记录。名称修正的操作表元数据、主页封面连续性等子面不能因其他表面成功而视为通过。

未授予能力的构建标记不适用，生产入口未启用的档案只作参考。必需成员缺失、歧义和运行时失败分别报告，不能借用其他构建资格或扩大候选掩盖缺口。

缺口未解决时保留其状态。以扩大候选、首个匹配或修改冻结夹具替代证据，不构成修复。

## 7. 人工验收记录方式

单次结果在对应任务记录中保存，按宿主、模块产物、设备和操作场景明确范围。profile 的 `runtimeVerified` 依据实际结果维护，静态契约匹配或构建成功不代表运行时通过；双栏/封面的反馈也不能代替歌词模糊验收。

局部场景确认不表示整项功能或整个构建通过。旧档案的 preserved-baseline 状态、缺省或 false 的 `runtimeVerified` 均不能解释为当前完整通过。

### 每个构建的结果记录模板

| 项目 | 填写要求 |
|---|---|
| 宿主身份 | 精确包名、版本名、版本号 |
| 模块身份 | 代码/构建版本和实际安装产物 |
| 环境 | 设备型号、Android、横竖屏/窗口、有效宽度与DPI |
| 条件 | 相关开关、账号/网络、歌曲与歌词/视频类型 |
| 场景 | 操作步骤、预期行为、实际结果 |
| 状态 | 已确认 / 待验收 / 不适用 / 已知降级 / 新异常 |
| 证据 | 使用者反馈、所需日志/截图/录屏及确认范围 |
| 检查阶段 | 源码/DEX、静态工具、构建、安装状态和人工结果分别记录 |

功能由使用者手动验收。没有设备、原始包或操作结果时保留待验收；记录环境和场景后才能将结果用于后续回归对照。
