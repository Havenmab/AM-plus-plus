# 宿主版本适配清单

每个精确构建独立使用本清单，包括复用已有页面族的构建。填写结果时区分“已核对”“未确认”“不适用”“已知降级”；不适用须注明 profile 资格或页面族依据。一个版本的结果不能代替另一个版本。

流程和实现边界见 [宿主适配手册](host-adaptation-guide.md)，功能语义和人工场景见 [功能保全与验收矩阵](feature-preservation.md)。单次执行记录保存在任务记录中，本文件作为可重复使用的模板。

## 1. 构建身份与工作范围

| 项目 | 本构建填写内容 |
|---|---|
| 精确身份 | 包名 / versionName / versionCode；二进制 Manifest 来源 |
| 安装包 | 格式、base、split 列表、DEX 和资源所在位置 |
| 代码基线 | 分支或提交、已有未提交工作、可回退代码和产物 |
| 对照宿主 | 对照构建及其页面族；复用的契约和独立分析范围 |
| 档案 | JSON 文件名、id、profileRevision、索引位置 |
| 页面族 | `legacy-activity` / `fragment-content` / 需新建的页面族 |
| 能力边界 | productionEnabled、glass、cellular、staticCollapsedIntercept、playerRecovery 等 |
| 证据范围 | 源码/DEX、资源、静态检查、构建、人工验收分别到哪一步 |
| 执行范围 | 所需源码分析、构建和使用者手动场景；其他检查是否有明确安排 |
| 数据约束 | 配置 schema、键、文件 ID、目录、数据库、缓存、ZIP 和插件接口 |

- [ ] 身份由实际 base Manifest 确认，外层清单和传入参数与其一致。
- [ ] 全部 DEX 与资源 split 已纳入分析，未假定 base 包含所有内容。
- [ ] 正式版、beta、同名不同 versionCode 分别建档。
- [ ] 未把旧混淆类仍然存在视为调用路径未变。
- [ ] profile 使用宿主原始类型与描述符，未复制反编译工具修复的类名、推断类型或冲突文件名。
- [ ] 当前支持构建与参考构建的资格已区分；已有不支持项和降级已记录。
- [ ] 默认不执行设备、功能脚本、全量测试或哈希检查；功能由使用者手动验收。

## 2. 版本数据与解析

### 2.1 profile 完整性

- [ ] 包名、版本名、版本号、文件名和唯一 id 对应同一组合。
- [ ] 页面族来自实际入口和布局，工厂已具备该族的能力实现。
- [ ] indexed、HLE hookTargets、运行时辅助成员和资源均有当前包的依据。
- [ ] 方法填写声明 owner、完整参数/返回类型和 static；字段填写 owner、类型和归属。
- [ ] 构造器、继承成员、接口返回关系、数组和 primitive 分别核对。
- [ ] Hook 目标为可用具体实现；抽象调用契约按需要注明 invocationOnly。
- [ ] 新档案使用 reject-ambiguous，未复制历史首个匹配例外。
- [ ] 旧 HLE 候选条目顺序和兼容语义保持；新 Fragment 契约使用当前精确档案。
- [ ] 开发期生产资格保持未启用；用户测试启用和运行时验收状态分别记录。
- [ ] verification、evidence、knownDegradations 与已取得证据一致。
- [ ] 源码、描述符和资源证据可追溯，引用的文档或位置有效。
- [ ] 索引只登记一次，既有条目的相对顺序保持。

### 2.2 逐成员证据模板

| 功能 / 角色 | 完整成员或资源 | 当前调用来源 / 含义 | 解析与调用决定 | 状态 |
|---|---|---|---|---|
| 待填写 | owner、签名或资源名及限定符 | 调用者、返回对象、原生读写位置 | 精确解析 / 允许的回退 / 调用形式 | 已核对 / 未确认 / 不适用 |

每个直接 Hook 入口继续展开其辅助成员。入口本身匹配不能代替 binding、getter、holder、listener、模型字段或清理方法匹配。

### CJK 辉光与末词扫光检查

实现、精确成员和后续版本维护规则见 [适配手册 7.2](host-adaptation-guide.md#cjk-animation)。

- [ ] 原辉光的单词作用域、前景字段、binding、触发门槛和结束清理按当前构建核对。
- [ ] `cjk.terminalGradient` 的 13 个方法、4 个字段角色与完整描述符有当前包证据；缺少契约时明确记录补偿不适用。
- [ ] 扫光/余量方法参数语义、羽化单位、末词 ID、原文/发音向量与延迟动画标签保持一致。
- [ ] reader 在文档或词序列更新时的替换/复用方式明确，末词缓存不会沿用到新数据。
- [ ] 同一 CJK 开关控制两部分安装；成员缺失或注册失败时新 hook 失活，原辉光保留。
- [ ] 手动观察短尾词全亮、长尾辉光、Latin 原生规则及开关重启；按实际设备、宿主和场景记录。
- [ ] 保留原生逐字时长、词分组、整行切换与位移，不将本项验收扩展为防中断或换行修正通过；跨行遮罩修复属独立能力，见[跨行歌词扫光检查](#lyric-wrap-sweep-checks)。

#### CJK 人工场景

| 场景 | 观察重点 |
|---|---|
| CJK 短尾词 | 最后一个字在原生时间内逐渐全亮，末尾不残留暗边或再次突然补亮 |
| 辉光长尾词 | 末词补偿和原辉光同时正常，原有缩放、回落、结束清理及位移保持 |
| 英文和 Latin 发音 | 保留原生扫光终点及延迟规则 |
| 切歌、循环、拖动进度 | 不把其他 reader 或其他词的末词结果用于当前动画 |
| 开关启停并重启 | 辉光与末词补偿由同一设置控制 |
| 不支持或缺失成员 | 原有辉光保留，补偿的不支持或降级原因可从能力安装信息区分 |

<a id="lyric-wrap-sweep-checks"></a>

### 跨行歌词扫光检查

实现、几何语义、精确成员与后续版本维护规则见 [适配手册 7.3](host-adaptation-guide.md#lyric-wrap-sweep)。本项与 7.2 的 CJK 末词补偿相互独立；CJK 项通过不代表本项通过，反之亦然。

- [ ] 当前精确档案声明顶层 `lyricWrapSweep` 且 `contractVersion = 1`；未声明版本记录不支持并保留原生。
- [ ] 19 个方法角色与 24 个字段角色有当前包完整描述符；类型关系（同 owner、参数类型、View/ViewGroup 归属、listenerMask/fadeMask 类型与 owner、两路暗色 int[]、四路词 Map、mediaBrowser/mediaPosition 返回）逐项核对。
- [ ] 遮罩键确认为视觉行首个 child 索引，不是 TTML lineId、歌词序号或 adapter position；`maskFirst`/`maskLast` 行范围与 `topMasks`/`bottomMasks` bank 归属有当前包依据。
- [ ] 仅 registered 且遮罩身份与方向一致的跨行词动画被接管；同一 flexbox/bank 只保留最新接管；单行、几何不完整和不支持的混合方向复合形状保持原生。
- [ ] 进度使用原生媒体浏览器位置的同一毫秒时间轴；初始及每帧进度由词 begin/duration 与当前位置得出，同一接管内只前进，Seek 后新接管可回退；时长最多缩至剩余段，未新建全局计时器。
- [ ] 延迟单行补亮（rush 动画）只在当前仍持有成功绘制的多行几何、且该几何仍有效时抑制写入；主扫光失败释放接管标记，补亮重新核对几何，失败时原生透传；跨行计划生成的两个羽化 stop 与 `mask.i` 均在片段边界内，末片段完成不提前点亮下一词，交接层仅保留已经实际绘制过的后继边缘。
- [ ] `maskUpdate` 参数确认为 `int[]`、`float[]`、装箱 `Float`；后继主扫光、补亮与静态写入均经该入口。仅已成功完成绘制的跨行遮罩记录交接边界，兼容颜色方向和有序四 stop 才保护，写入成功后才推进记录；保留原版颜色、`mask.i`、动画时长与调度。
- [ ] 跨行长 span → 同行短 span 的完全亮色边缘与渐变前沿连续；两个 stop 分别单调，不能只限制单个 Sweep 的整词进度。LTR/RTL 对称，不提高原版前沿导致短后继余量非正，也不影响无跨行前段的原生单行扫光。
- [ ] 交接保护使用不可变几何快照；宽度、TextView/Layout、文本或遮罩身份失效即释放。暗色/未来 W 在原版写入前清对应 bank，纯暗色遮罩写入、退场、Seek、换绑/回收、文档替换、清空遮罩、布局变化及作用域关闭均清保护。
- [ ] `staticMask`（W）每次先清掉同 flexbox/bank 的旧帧；词为空、未开始、前缀调色板为原生暗色或形状不支持时保留原生。其余已开始的跨行词在存在活动接管时按其最新进度、颜色与羽化重绘，无接管时按当前位置重建；`rebind`（i0）与布局变化后几何失效并按当前状态重绘，羽化随当前宽度重算。
- [ ] 区分未来行初始化与已唱词恢复；缓存重绘前复核词 begin，未开始的词不能因零进度映射而点亮 span 前缀或后续未播放的歌词行。
- [ ] `foregroundInactiveColors`/`backgroundInactiveColors` 与原版 W 的比较语义一致；已唱但不活跃的行不被静态恢复重新点亮。`fadeUpdate`/`fadeMask` 覆盖绕过 W 的退场写入，核对当前遮罩 bank 身份后清缓存并退役旧写入；原版渐暗继续执行，旧遮罩回调不影响新绑定。
- [ ] 入场渐亮的暗色首帧不退役活动扫光；静态帧与布局重绘均遵守原版亮暗状态，退场曲线和调度由宿主控制。
- [ ] `rebind` 核对当前 holder 四路词 Map 的对象身份和文本/Layout 身份；`bind`/`recycle`/`document`/`clearMasks`/`seek` 退役旧回调与静态帧；Seek 取消旧词动画集释放 `word.o`，`pause`/`pauseRequested`/`resume` 同步原生词动画；作用域关闭清理布局监听。
- [ ] 缺少契约或注册失败时能力明确降级，回调异常只记录一次同类原因并保持原生透传。
- [ ] 结果按具体版本、设备和场景记录；未执行保持待验收，静态成员匹配或构建成功不等于真机通过。

#### 跨行歌词扫光人工场景

| 场景 | 观察重点 |
|---|---|
| 两行跨行词 | 高亮按实际字形宽度跨两行连续推进，行首/行尾无暗边残留，第二行不落后也不提前 |
| 从头播放且未来行可见 | 未到时间的行始终保持原生暗色，包括未来行的最后一个 span 跨视觉行、span 前存在其他词的情况；预加载、重新绑定与布局刷新不会提前高亮 |
| 已唱行退场及重新显示 | 原生渐暗连续执行，退场后布局刷新或重新绑定不恢复旧亮色；过期遮罩的渐暗回调不撤销新行接管 |
| 当前行入场渐亮 | 暗色首帧不提前结束活动扫光，亮度曲线继续使用原版动画 |
| 三行跨行词 | 累计宽度按文本顺序推进；末行完成时整词全亮，无补亮覆盖 |
| 跨行长 span → 同行短 span | 上一段尾部已亮文字不被下一段羽化重新画暗，后一段仍按原版时间扫光；手机/平板改变视觉行数后交接仍连续 |
| 后继补亮或静态刷新 | 兼容方向的两个 stop 不回撤，原版颜色变化继续；原几何无效或暗色状态不沿用旧亮边 |
| 原生单行 span、不同遮罩或相反方向 | 没有已完成跨行遮罩保护的写入保持原生，不按固定字数、歌词内容或设备种类特判 |
| 词内中段 Seek（之前 / 之后） | Seek 后按新的当前位置重建进度；旧接管不写入新位置 |
| 暂停 / 恢复 | 原生动画随播放暂停与恢复；恢复后进度连续，无跳变重复刷新 |
| 切歌 / 行回收 | 换绑与回收后旧回调不写入新行；新行按自身状态从头推进 |
| 字体或字号变化、旋转、双栏 | 布局重建后按新几何继续；旧几何失效，不沿用旧宽度；扫光期间或末尾无法接管时原生补亮可继续写入 |
| 原文（TOP）与发音（BOTTOM）词 | 同一 flexbox 内只接管该词所在 bank；另一 bank 保持原生 |
| 前景与背景词 | 前景与背景是两个独立 flexbox，各自独立接管或保持原生；不能把 TOP/BOTTOM 当作前景/背景 |
| RTL 歌词 | 渐变方向与行内推进方向与文字方向一致 |
| 混合 Bidi 或复合形状 | 明确不支持时保持原生渲染，能力状态可区分 |
| 关闭 CJK 辉光 / 未声明契约的版本 | 跨行修复独立于 CJK 开关；未声明契约时报告不支持并保留原生 |

### 歌词模糊检查

显示规则、状态分层、独立契约、效果所有权与诊断见 [适配手册 7.1](host-adaptation-guide.md#lyrics-blur)。

- [ ] 必需角色、profile 和离线维护清单同步，模糊资格不依赖双栏。
- [ ] 完整 owner、类型和接口关系有当前包证据；原生 ID 与 adapter 稳定 ID 角色分开。
- [ ] 已应用快照与 raw 事件分开，核对子集保留、列表动画等待和 Handler 提交。
- [ ] 行 ID、歌词序号、列表位置分开，绑定代际和 holder 身份可校验。
- [ ] 四路文字动画与装饰分开，辉光/位移不延长保护，文字结束/取消与 Seek 清理完整。
- [ ] 首句/末尾时间、播放位置和三点实际显示状态可读；延迟三点可切换，真实高亮优先，结尾保留有效焦点。
- [ ] 每个 root 独立会话，暂停打开有首帧，同 wrapper 文档重装更新代际。
- [ ] 用户浏览、惯性和程序滚动区分，1秒恢复任务校验代际。
- [ ] 逻辑行动画、换绑、边缘变换、效果所有权和整组失败释放有明确路径。

#### 歌词模糊人工场景

| 场景 | 验收标准 |
|---|---|
| 逐行首句、三点消失 | 首句连续渐清，不上下错行；区分目标 0 与 300ms 内的实际非零半径 |
| 无三点前奏、暂停打开 | 文档首句清晰，后续原曲线模糊，首帧不依赖下一次播放 |
| 三点延迟加载 | 显示后平滑切回间奏距离；已经高亮的行仍目标 0 |
| 两行重叠、集合缩小、动画等待 | 与宿主实际显示对应，重复事件不延长动画 |
| 主词、背景词、发音和重叠词 | 保护随实际显示释放，没有旧词长期残留 |
| 带辉光的旧行 | 文字高亮退出后立即开始原 300ms 渐模糊，辉光/上浮/回落继续由宿主运行 |
| 末句结束、暂停重开 | 原模糊分布保留；换歌、清空和 Seek 不携带旧结尾焦点 |
| 拖动、长按、惯性、程序滚动 | 浏览持续解除焦点模糊，结束 1 秒后恢复；自动跟随不误入浏览 |
| 高频拖动进度 | 旧高亮、词流和恢复任务不污染新位置 |
| 快滚、字体与翻译变化 | View 复用不继承其他歌词半径 |
| 换歌、清空、同 wrapper 替换 TTML | 文档状态完整更新，不残留旧行身份 |
| 旋转、后台、全屏与右栏 | 首帧正确，会话独立，旧回调不能修改新视图 |
| 平板边缘、缩放与位移 | 边缘随当前几何和 padding 更新，高亮渐清连续 |
| 创作者行、短行与视口边界 | 模糊自然扩散，没有逐行矩形切边；文字位置不变，滚动不越出歌词视口；清晰后恢复宿主裁剪 |
| 关闭、退出、契约或 Hook 缺失 | 释放模块效果，保留宿主透明度和自身效果，能力状态如实降级 |

### 歌词结果提交检查

提交层、安装确认、结果一致性与降级规则见 [适配手册 7.6](host-adaptation-guide.md#lyrics-result-submission)。本项是自定义歌词与自动补全共用的结果通道；查询、来源顺序和缓存策略仍按各自检查项核对。

- [ ] 结果容器、发布入口、派生时间范围索引重建和当前歌词身份读取均有当前包完整描述符，声明实际 owner、类型和调用形式。
- [ ] `pointerScript` 的完整签名为 `SongInfoNative.setScript(String): boolean`；逐项核对返回类型，未将忽略返回值的 setter 误登记为 void。
- [ ] 由 `LyricsResultSubmissionBridge.create` 按当前精确 profile 解析并持有目标；缺少任一必需角色时该能力明确降级并保留原生歌词。
- [ ] 原生安装入口、歌词 Fragment 恢复及原生 item 更新回调后附加当前 ViewModel，读取已存结果并恢复请求身份；未改写安装参数、未持有 ready-late 台账，也未启用旧重应用或协调器活动路径。
- [ ] 界面刷新由原生观察者和原生安装入口完成，模块未重入 Fragment 安装方法。
- [ ] 不主动改写 Fragment 当前 item；通过既有精确 itemUpdate 条目的 after 观察在原生 item 更新后重新附加，未在其他位置改写 item。
- [ ] 安装入口 after 观察仅在调用无异常、ViewModel 精确、指针与 Fragment 及请求 ID 一致时确认安装；确认只表示安装调用返回，不代表界面已完整渲染。
- [ ] 选择与安装确认分开：身份对齐后，未确认安装的指针允许经结果容器补发，每次外部恢复回调最多一次；确认后去重，自身写入不会通过 installer-before attach 再次排队。
- [ ] 更换请求、ViewModel 或关闭会话时清除待安装状态；换到新 Fragment 实例且已有选中结果时重新等待确认，同实例重复附加不重置确认；身份不符时暂缓模块替换。
- [ ] 结果通道角色清单保持 11 个方法与 2 个字段不新增；item 更新回调复用既有精确条目并随同一精确 profile 解析，profile 未命中时通道降级。
- [ ] `resultSet`/`resultPost` 指向实现发布逻辑的精确 LiveData 基类，按结果容器实例过滤；`resultValue` 和 `fragmentResume` 完整登记。
- [ ] 原生结果先就绪、ViewModel 复用、短转发方法被 ART 内联时，仍能从已有结果恢复并提交自定义歌词。
- [ ] 后台结果到达且当前身份与安装上下文匹配时立即提交；身份不符时可在原生 item 更新后恢复，无须重新查询。
- [ ] 提交在主线程进行，与原生结果写入同一线程；未从后台线程直接写结果容器。
- [ ] 提交前核对播放请求代次与当前 Apple Music ID，陈旧结果不提交；ViewModel 会话结束或播放请求更换后丢弃迟到结果。
- [ ] 结果容器与派生时间范围索引在同一次提交中按同一文档更新，当前歌词身份读取返回新文档。
- [ ] 替换文档在通知观察者前索引已就绪：先按新文档重建派生索引，再写入结果容器并交付观察者。
- [ ] 结果容器写入先保存后通知；提交抛异常不能单独判断写入是否已经提交，未用第二次 setValue 回滚，而是读取 resultValue 实际保存的文档，把选择与派生索引对齐到该文档。
- [ ] 异常恢复仅在会话仍有效时写回：同 ViewModel、同结果容器、同请求代次成立才对齐；期间切歌、ViewModel 更换或会话关闭时不写旧会话状态。
- [ ] 读取实际保存值或重新构建索引本身失败时，只记录一次同类原因并使索引成功标记失效，保留下次重建机会，未把该次提交当作恢复成功。
- [ ] 派生索引成功只在当前请求同一存活指针上复用；实际重建前、调用上下文 setScript 前、请求或 ViewModel 结束时均失效，无跨请求复用。
- [ ] 原生普通发布不重复扫描：模块预建后的同指针原生后续构建仅跳过一次，其他原生调用仍执行；postValue 先构建后主线程交付可复用成功结果。构建失败或同一 ViewModel 构建交叠、过期时撤销复用资格，保留重试机会；未把观察者异常误作索引构建失败。
- [ ] 原生自身加载的迟到结果也经过同一选择与提交规则，按现有来源优先级和原生文档质量决定保留或替换。
- [ ] 附加当前歌词 ViewModel 时，容器内仍是上一首结果也不影响绑定：仍绑定当前 ViewModel 与结果容器并等待当前文档，未按已有值直接接管。
- [ ] 加载入口未命中时按已验证的当前播放身份与歌词页面身份恢复请求绑定，实时指针与当前文档一致才注入；未从回调到达顺序或代次推断。
- [ ] 显式 loadLyrics 捕获的请求 ID 不被按身份恢复覆盖；缓存核验只控制模块替换资格，已捕获请求或已领先的新请求不被缓存滞后改写。
- [ ] 请求身份区分显式捕获与推断：显式捕获不被覆盖；非显式推断身份可据附加 Fragment 当前 item ID 与同一 ViewModel 的独立佐证修正，缓存滞后仍保住原生结果。
- [ ] 推断身份佐证限定在无法判为已知旧身份时；缓存与 Fragment 身份不一致且 Fragment 身份为最近已发布歌曲（可重新绑定）时，未用该旧 Fragment 与迟到指针反推覆盖缓存，身份不确定或多次往返时保守等待。
- [ ] 同一 ViewModel 附加不覆盖已捕获的非零请求；请求退役与 ViewModel 更换按各自生命周期处理；播放身份通知按实际 ID 变化处理，同一 ID 的重复通知不清除领先请求。
- [ ] 原生 item 更新把 Fragment item 从旧身份改到新身份而当前请求仍是旧身份时只退役旧请求，已领先的新请求不变；播放缓存缺失且加载入口未命中时可从 Fragment 当前 item 恢复，不因保留失效的非零请求而无法恢复。
- [ ] 无文档身份的空值或错误发布在已确认的当前文档存在时被抑制，结果容器与派生索引继续指向该文档。
- [ ] 空信号只在确认当前没有可用文档时进入既有降级路径。
- [ ] 已观察到空态后，仍能恢复绕过写入 Hook 的当前有效实时指针；模块替换指针未被当作原生文档参与质量判断。
- [ ] `postValue` 只读观察：未取消原生调用、未用 mainHandler 逐条转交 setValue；同一原生主线程投递任务执行前的多次发布由结果容器合并，只交付最后一个值，中间被覆盖的值不触发模块提交选择或额外结果通知；宿主索引调用仍参与既有的一致性处理。
- [ ] 只对无文档身份的空 Pair 以弱引用记录发布代次；交付时标签早于最近真实请求/owner 边界（原生加载请求、更换 ViewModel、实际切歌、请求退役、ViewModel 清空、会话关闭）才拒绝该空 Pair。目标容器不再被跟踪或会话关闭时模块不再接管写入，保留宿主原生交付。
- [ ] 未知绑定恢复只改变内部代次、不推进真实边界；同一请求内的恢复不误拒空 Pair，原生空态不会因此永久停留在未观察状态。
- [ ] 非空结果在交付时按当前请求与实时身份判定；未用入队时的播放缓存快照拒绝当前歌曲。
- [ ] 待匹配候选与重试：item ID 与当前播放身份暂不一致的 Fragment 以有界弱引用候选记住（Fragment 与初次记录的 ViewModel 各持一个弱引用），不立即采用、不改写 Fragment item；缓存或就绪回调在主线程先重读当前身份与选择器，再按当前 ID 匹配候选，且仅当 ViewModel 字段仍为初次记录的同一实例、View 未销毁时才附加。
- [ ] 活动 owner 优先：仅在已有歌词面板 owner 的 View 仍附着、其 ViewModel 字段就是当前跟踪实例、且 Fragment ID 匹配当前请求/当前身份时，才阻止同歌曲旧候选替换；一次请求捕获本身不足以判定活动 owner，无 owner 的 load 或已脱离、销毁的旧面板不阻止新候选。
- [ ] 候选清理与唤醒：ViewModel 清空、会话关闭、候选回收或 View 销毁时移除对应候选；当前 ViewModel 清空时一并清除已跟踪 owner 并唤醒其余候选。
- [ ] 就绪回调在交付时重新读取当前身份与选择器，不因一次未知绑定恢复引起的内部代次变化而丢弃唤醒。
- [ ] 未新增 profile 成员、宿主私有字段或新类；空 Pair 代次标签复用现有弱标识映射，候选验活仅使用 Fragment 公开 `getView`；该公开 API 无法解析时结果通道降级。
- [ ] 以解析器给出的文档文本身份标识本次结果并按请求去重；已确认交付的同一文档不重复提交，文本身份相同而对象不同的候选按同一文档处理。
- [ ] 手动条目优先于自动补全；歌曲被禁用时不注入；沿用原生歌词可用性谓词，未放宽或收紧资格。
- [ ] 模块只对当前歌词 ViewModel 实例提交，未替换或改写 LiveData 全局类型、未注册全局观察者；翻译与发音等订阅者不受影响。
- [ ] 查询、解析、来源顺序和缓存策略保持不变，仍沿用既有业务路径。
- [ ] 提交或索引重建异常时 fail-open，保留宿主既有结果并只记录一次同类原因；写入抛异常不能单独判断写入是否已经提交，未二次写入回滚，读取或重建失败时撤销索引复用资格。
- [ ] 新增依赖同步登记到当前 profile 与 `scripts/verify-host-profile.py` 的必需角色清单。
- [ ] 结果按具体版本、设备和场景记录；未执行保持待验收，静态匹配或构建成功不等于真机通过。

| 空 Pair 跨真实边界 | 交付时发现已跨真实请求/owner 边界，空结果被拒绝；仅同请求内的绑定恢复不误拒，已确认文档与派生索引不变 |

### 底栏收缩渲染检查

启用边界、效果复用与生命周期规则见 [适配手册 7.4](host-adaptation-guide.md#glass-collapse-rendering)。本项核对渲染语义与复用边界，性能结论应结合目标设备的测量记录。

- [ ] `LiquidBottomTabs` 的 `optimizeCollapseRendering` 默认为 `false`；只有 `GlassNavigation` 在 `collapseProgress != null` 时置为 `true`，不具备收缩的宿主仍使用原始渲染路径。
- [ ] 与尺寸无关的 `vibrancy()`+`blur(radiusPx)` 前缀以像素半径为键复用；Dp 按当前密度换算，像素半径变化时重建；`lens` 等依赖尺寸、按压或圆角的效果仍按帧求值，效果顺序与复用前一致。
- [ ] 通用渲染器 `minLayerSize` 默认零，默认裁切仍为 `Offscreen`；新增的最小承载尺寸与 `Auto` 裁切只由收缩路径启用，旧构建和平板没有进入新增路径。

- [ ] mini 只在已启用收缩且完整播放器展开进度为零时预留承载层，打开／收回播放器、原生按钮和拖动保持现有行为；无 mini 时左右按钮仍按原规则收缩。

- [ ] 上游本地补丁的来源说明与源码 pin 同步维护；设备人工对比覆盖收缩／展开整段动画、稳定滚动和材质轮廓，不能仅凭编译通过认定性能已改善。

- [ ] 辅助类型位于上游命名空间之外（`dev.amenhancer.backdrop`），不修改 `com.kyant.backdrop` 上游效果源；材质 modifier 在启用路径下按 backdrop、半径和材质输入 `remember` 复用。

- [ ] 上述折射源与分离搜索的节点在挂起和恢复之间保留资源，门禁翻转后在下一帧绘制前恢复测量与放置。

#### 底栏收缩渲染人工场景

| 场景 | 观察重点 |

| 切页、旋转、关闭开关 | 展开过渡保持同步，渲染复用不残留旧状态 |
